# PulseBoard Demo App

A lightweight productivity dashboard built with React, Vite, TypeScript, and Tailwind CSS.

## Features
- Add tasks with priority levels
- Mark tasks complete or active
- Search and filter tasks
- Local storage persistence
- Responsive task dashboard
- Dark mode toggle

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```bash
http://localhost:3000
```

## Build

```bash
npm run build
```
